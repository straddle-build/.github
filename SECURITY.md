# Security Policy

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting for the affected repository. If the repository does not expose that option, report the vulnerability through [straddle-build/.github security advisories](https://github.com/straddle-build/.github/security/advisories/new).

Include the affected project and version, reproduction steps, impact, and any known mitigation. A maintainer will acknowledge the report and coordinate disclosure.
